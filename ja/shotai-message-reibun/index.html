招待メッセージ 例文20選: お誘いから出欠確認、前日のリマインドまで

よい招待メッセージは、1、2行で五つのことを伝えます。何の集まりか、いつ、どこで、誰を招くのか、そしていつまでに返事がほしいかです。ここでは誕生日会、ホームパーティー、忘年会、結婚式にそのまま使える招待メッセージと出欠確認の例文20選と、ゲスト一人ひとりに別々に送る方法をまとめました。

この記事の最後に出てくるアプリSendrは私たちが作っています。例文はどのメッセージアプリでも使え、アプリは必要ありません。

集まり送る時期必ず入れること返信の期限
誕生日会2、3週間前誰の誕生日か、日付、時間、場所1週間前
ホームパーティー、食事会1、2週間前日付、時間、住所、持ち物3〜5日前
忘年会、年末の集まり11月中、3、4週間前日付、時間、場所、会費1週間前
結婚式、二次会招待状やWeb招待状のあと名前、日付、会場、出欠の回答リンク招待状に書いた期日
出欠確認のリマインド期限の2、3日前集まり、期限、返事の仕方期限当日

招待メッセージには何を書けばよいですか?

招待メッセージには、集まりの名前、日付と開始時間、場所、誰を招くのか、返信の期限を書きます。日付と時間は通知のプレビューに表示されるよう、最初の行に置きます。駐車場、服装、持ち物など役立つ情報を一つだけ加え、残りはリンクに任せます。

下の例文の{first_name}はゲストのお名前が入る差し込み項目で、[日付]や[住所]のように角かっこで囲んだ部分はご自身で入れます。「わかったら教えてね」より「[日付]までに教えてね」と期限を書くほうが返事が早く集まります。今返す理由ができるからです。

誕生日会の招待メッセージ 例文

誕生日会の招待メッセージには、誰の誕生日か、いつどこで始まるか、いつまでに返事がほしいかを書きます。子どもの誕生日会なら、終わりの時間と保護者の付き添いが必要かも伝えます。2、3週間前に送り、1週間前までに返事をもらうと、料理や席の準備がしやすくなります。

  1. {first_name}ちゃん、久しぶり!今度[名前]が[年齢]歳になるので、[日付][時間]から[場所]でお祝いするよ。来られそう?[日付]までに教えてね。
  2. {first_name}さん、[日付][時間]から[お店]で誕生日ディナーをします。お店を予約したいので、[日付]までに返事をもらえるとうれしいです!
  3. {first_name}さん、こんにちは。[日付][時間]〜[時間]に[場所]で[お子さんの名前]の誕生日会を開きます。[ゲストのお子さんの名前]ちゃんも来てくれたらうれしいです。[日付]までにお返事ください。
  4. サプライズパーティーのお知らせ![日付][時間]から[場所]で[名前]の誕生日をお祝いします。本人には内緒で、[日付]までに私だけに返信してね。
  5. {first_name}さん、[年齢]歳になりました![日付][時間]から[場所]で飲んでいるので、都合のいい時間にふらっと来てね。来られるかだけ返事ください。

ホームパーティー、食事会、忘年会の招待メッセージ 例文

ホームパーティーや食事会の招待メッセージはくだけた文でかまいませんが、日付、時間、住所は必ず入れます。料理の内容や持ってきてほしいものを書き、数日前までに返事をもらいます。12月は予定が早く埋まるので、忘年会や年末の集まりは3、4週間前に声をかけます。

  1. {first_name}さん、[日付][時間]からうちでごはん会をします!住所は[住所]です。[日付]までに来られるか教えてね。苦手な食べ物があれば一緒に。
  2. {first_name}ちゃん、[日付][時間]から友だち何人かで新居祝いをするよ。飲み物を一つ持ってきてくれたら十分!人数を知りたいので[日付]までに返事ちょうだい。
  3. {first_name}さん、[日付][時間]より[場所]で忘年会を開きます。会費は[金額]です。ご出欠を[日付]までにお知らせください。
  4. {first_name}さん、[日付][時間]から[場所]でボードゲーム会をやります。[日付]までに「参加」か「不参加」で返事をくれたら席を取っておくね。
  5. {first_name}ちゃん、[日付][時間]から[住所]で持ち寄りの年末パーティーをするよ。何を持ってきてくれるか、[日付]までに教えてね。

結婚式、二次会、改まった集まりの招待メッセージ 例文

結婚式や二次会のような改まった集まりでは、メッセージは招待状やWeb招待状を補う役目です。温かく短く書き、名前は正確に入れ、出欠の回答リンクか招待状に書いた期日を案内します。招待状を送ったあとに送り、それより先には送りません。

  1. {first_name}様、このたび[名前]と[名前]は[日付]に[都市]で結婚式を挙げることになりました。招待状はこちらです: [リンク] [日付]までにご出欠をお知らせください。
  2. {first_name}さん、[日付][時間]より[会場]で[名前]の結婚式二次会を開きます。準備のため、[日付]までにお返事をお願いします。
  3. {first_name}様、[日付][時間]より[会場]にて[行事]を執り行います。ぜひご出席いただければ幸いです。詳細と出欠のご回答: [リンク]
  4. {first_name}さん、招待状はもうすぐ届きますが、先にお知らせです。[日付]、[都市]で結婚式をします。予定を空けておいてもらえるとうれしいです!
  5. {first_name}様、[名前]さんの送別会を[日付][時間]より[場所]で行います。ご参加いただける場合は、[日付]までに[名前]までご連絡ください。

出欠確認とリマインドのメッセージ 例文

出欠確認のメッセージは、返信の期限をもう一度伝え、返事をしやすくするためのものです。最初の確認は期限の2、3日前に送り、一言で答えられる聞き方にします。期限を過ぎたら返事のない人だけに送り、前日には全員に短いリマインドを送ります。

  1. {first_name}さん、確認です。[日付]の[集まり]には来られそうですか?[日付]までに「参加」か「不参加」で返信をお願いします。
  2. {first_name}様、[日付]の[集まり]の人数を確定いたします。本日中にご出欠をお知らせいただけますか。
  3. {first_name}ちゃん、一つだけ確認させて。[集まり]には誰かと一緒に来る?席を決めたいので[日付]までに教えてね。
  4. {first_name}さん、明日[時間]から[集まり]です!住所は[住所]、駐車場は[場所]を使ってください。
  5. 連絡ありがとう、{first_name}さん!今回は会えなくて残念。終わったら写真を送るね。

グループを作らずゲスト全員に招待メッセージを送る方法

ゲスト一人ひとりに別のメッセージを送ります。1通に全員を入れると、iPhoneではグループになり、お互いの番号やすべての返信が見えてしまうことがあります。別々に送れば出欠の返事がゲストごとのトークに届くので、グループをさかのぼらずに参加と不参加を数えられます。

iPhoneでは、Sendrがメッセージアプリを通じて、あなたの番号からゲスト一人ずつに別のメッセージを送ります。{first_name}を入れて招待の文面を1回書き、連絡先か保存したゲストのグループを選び、確認して送信の画面で1通ずつ確認します。どのメッセージも個別に直せます。iMessageとSMSには、招待状の画像など写真や動画を3つまで添付できます。1件ずつ送信は無料で、Sendrがゲストごとにメッセージを開き、送信はあなたがタップします。Proの自動で送信は、ショートカットを1回設定すれば、iPhoneのロックが解除されている間リストを順に処理します。終わるとレポートで、招待メッセージを送れた相手と送れなかった相手がわかり、残りに送信で残りの相手に続けて送れます。SendrはiPhone専用です。

SMSで届く可能性がある文面は、全角70字を目安にしましょう。超えると分割され、料金が変わる場合があります。

SMSの文字数は2026年11月に確認しました。

よくある質問

招待をLINEやメッセージで送るのは失礼ですか?

誕生日会、ホームパーティー、食事会なら、メッセージでのお誘いで問題ありません。結婚式など改まった集まりは、招待状やWeb招待状を先に送り、メッセージは案内や出欠確認に使うのが一般的です。

招待メッセージはいつ送ればよいですか?

誕生日会は2、3週間前、気軽な食事会は1、2週間前、12月の忘年会は3、4週間前が目安です。前日に短いリマインドをもう一度送ります。

出欠確認のメッセージはどう書けばよいですか?

「金曜日までに参加か不参加で返信してね」のように、期限と簡単な質問を一緒に書きます。期限の2、3日前には、まだ返事のない人だけに送ります。

グループを作らずに大人数へ招待を送るには?

ゲストごとに別のメッセージを送ります。一人ずつ手で送るか一斉送信アプリを使えば、返事はそれぞれのゲストとの個別のトークに届きます。

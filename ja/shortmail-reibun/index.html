よいショートメールの文面とは?

よいショートメールの文面には四つの要素があります。相手のお名前、自分の名前か社名、はっきりした用件一つ、そして次にしてほしいこと一つです。SMSは全角70字までが1通の目安なので、店頭でそのお客様に話すつもりで短く書きます。

変わる部分は空けておきます。下の例文の{last_name}と{company}は差し込み項目で、[日付]や[時間]のように角かっこで囲んだ部分はご自身で入れます。手で書き換えるか、アプリに相手ごとにお名前を入れてもらいます。

1通の用件は一つにします。予約の確認に口コミのお願いとセールの案内まで入れると、どれも伝わりません。

予約確認のショートメール 例文

予約確認のショートメールには、日付、時間、確認や変更の方法を書きます。前日の日中に送り、無断キャンセルが痛い業種なら2時間前にもう一度送ります。日付と時間は通知のプレビューに表示されるよう、文の初めのほうに置きます。

  1. {last_name}様、{company}の[名前]です。[日付][時間]のご予約のご確認です。ご都合がよろしければ「はい」とご返信ください。
  2. {last_name}様、明日[時間]にお待ちしております。変更をご希望の場合はこのメッセージにご返信ください。[名前]
  3. {last_name}様、本日[時間]に{company}でご予約をいただいております。住所は[住所]です。お気をつけてお越しください。
  4. {last_name}様、{company}です。前回のご来店から[半年]がたちました。ご予約をお取りしましょうか。ご希望の日をお知らせください。
  5. {last_name}様、本日はお会いできず残念でした。あらためてご予約をご希望でしたら、ご都合のよい日時をご返信ください。[名前]

フォローのショートメール 例文

フォローのショートメールは、打ち合わせ、ご来店、お見積りから1日以内に送るのが効果的です。相手が内容を覚えているうちに届くからです。何の件かを書き、質問は一つにし、一言で返信できるようにします。返信がなければもう一度だけ送り、そこで止めます。

  1. {last_name}様、本日はご来店ありがとうございました。[内容]についてご不明な点があれば、こちらにご返信ください。[名前]
  2. {last_name}様、[日付]に[案件]のお見積りをお送りしました。内容はいかがでしょうか。修正があればお知らせください。[名前]
  3. {last_name}様、[サービス]のその後はいかがでしょうか。気になる点があればすぐにご連絡ください。{company} [名前]
  4. {last_name}様、[イベント]でご挨拶した[名前]です。お約束どおり連絡先をお送りします。{company}
  5. {last_name}様、ご連絡はここまでといたします。[案件]がまた必要になりましたら、いつでもご連絡ください。[名前]

お知らせのショートメール 例文

お知らせのショートメールは、最初の一文に用件を書きます。何が、いつから変わるのか、相手にしてほしいことがあるかを伝えます。営業時間の変更、休業、日程の変更、商品のご用意に使えます。相手はこの文面どおりに動くので、送る前に日付を二度確認します。

  1. {last_name}様、{company}は[日付]に休業いたします。[日付][時間]より通常どおり営業いたします。
  2. {last_name}様、[日付]より{company}の営業時間が[時間]に変わります。ご来店の際はご注意ください。
  3. {last_name}様、ご注文の品のご用意ができました。本日は[時間]まで{company}でお受け取りいただけます。
  4. {last_name}様、[曜日]の練習は[時間]、[場所]に変更になりました。ご確認いただけましたらご返信ください。[名前]
  5. {last_name}様、{company}は移転いたしました。[日付]より新住所[住所]でお待ちしております。

ご案内と招待のショートメール 例文

招待のショートメールには五つの情報を入れます。何の集まりか、いつ、どこで、誰が対象か、どう返事をするかです。パーティーは2、3週間前、会合は数日前に送り、前日に短いリマインドを送ります。準備のために返信の期限も書いておきます。

  1. {last_name}様、[日付][時間]より[場所]にて[イベント]を開きます。ご出欠を[日付]までにご返信ください。
  2. {last_name}様、保護者会を[日付][時間]より[場所]で行います。所要時間は約[40分]です。ご欠席の場合はご返信ください。[名前]
  3. {last_name}様、{company}では[日付][時間]より内覧会を開きます。お知り合いとご一緒にお気軽にお越しください。
  4. {last_name}様、[イベント]は明日[時間]からです。駐車場は[場所]をご利用ください。お待ちしております。[名前]
  5. {last_name}様、[イベント]にお越しいただきありがとうございました。写真はこちらからご覧いただけます: [リンク] [名前]

口コミ、ご紹介、お支払いのお願い 例文

口コミやご紹介のお願いは、よい結果が出た直後に一度だけにします。お支払いのお願いには、金額、期日、お支払い方法を落ち着いた言葉で書きます。いずれも、すでにお取引のある方だけに送る文面で、面識のない方のリストには送りません。

  1. {last_name}様、{company}をご利用いただきありがとうございました。お時間のあるときに口コミをいただけると励みになります: [リンク]
  2. {last_name}様、[結果]が無事に済み、うれしく思います。お知り合いに[サービス]をお探しの方がいらしたら、私の連絡先をお伝えください。[名前]
  3. {last_name}様、ご請求[番号]、[金額]のお支払い期日は[日付]です。お支払いはこちらから: [リンク] {company}
  4. {last_name}様、[日付]が期日のご請求[番号]、[金額]のご入金がまだ確認できておりません。ご入金の予定日をお知らせいただけますか。[名前]
  5. {last_name}様、ご入金を確認いたしました。ありがとうございました。{company} [名前]

グループを作らずリスト全員に例文を送る方法

一人ずつ別のメッセージを送ります。1通に全員を入れると、iPhoneではグループになり、お互いの番号や返信が見えてしまうことがあります。人数が少なければ、トークごとに例文を貼り付けてお名前を変えます。人数が多ければ、一斉送信アプリがその作業を代わりに行います。

iPhoneでは、Sendrがメッセージアプリを通じて、あなたの番号から一人ずつ別のメッセージを送ります。{last_name}を入れて文面を1回書き、連絡先か保存したグループを選び、確認して送信の画面で1通ずつ確認します。どのメッセージも個別に直せます。文面はテンプレートとして保存し、次回また使えます。1件ずつ送信は無料で、Sendrが相手ごとにメッセージを開き、送信はあなたがタップします。Proの自動で送信は、ショートカットを1回設定すれば、iPhoneのロックが解除されている間リストを順に処理します。終わるとレポートで、送れた相手と送れなかった相手がわかります。SendrはiPhone専用です。

SMSで届く可能性がある文面は、全角70字を目安にしましょう。超えると分割され、料金が変わる場合があります。

SMSの文字数は2026年11月に確認しました。

よくある質問

ショートメールは何文字までにすればよいですか?

SMSで届く可能性があるなら全角70字が目安です。超えると分割して送られ、料金が変わる場合があります。用件を一つに絞ると収まりやすくなります。

iPhoneでショートメールの定型文を保存できますか?

メッセージアプリに定型文の機能はありません。メモに文面をまとめて貼り付けるか、キーボード設定のユーザ辞書によく使う文を登録するか、テンプレートを保存できるアプリを使います。

お客様にショートメールを送るには同意が必要ですか?

広告や宣伝のメッセージには、事前の同意と配信停止の方法を求めるルールがあります。予約の確認などの連絡は扱いが異なりますが、送る前にルールを確認してください。

人数が多いとき、例文をどう一人ひとりに合わせますか?

お名前の場所に{last_name}のような差し込み項目を入れ、一人ずつ別のメッセージで送ります。大切なお客様には一言を手で書き添えます。

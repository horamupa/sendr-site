お礼メッセージ 例文20選: 場面別にお客様へ送る文面

お客様へのお礼メッセージは2、3文で十分です。お名前を入れ、何に感謝しているかを一つ具体的に書き、何もお願いしないことが大切です。この記事では場面別にそのまま使える例文20選と、一人ずつ別々に送る方法を紹介します。

この記事の最後に出てくるアプリSendrは私たちが作っています。例文はどのメッセージアプリでも使え、アプリは必要ありません。

場面送る時期書くこと避けること
初めてのご購入、ご来店当日購入、予約された内容別の商品のご案内
納品、作業の完了2日以内うまくいった点を一つ請求の催促
長いお付き合いのお客様初回ご注文の記念日お付き合いの長さお礼に見せかけた割引
ご紹介、口コミ1日以内紹介された方、書かれた内容別のお願い
年末12月15日から30日今年一緒にしたことを一つ年末セールの案内

お礼メッセージには何を書けばよいですか?

お礼メッセージに書くのは、自分が誰か、何に感謝しているかの二つだけで十分です。整った定型文より、実際にあった出来事を一つ書くほうが伝わります。仕上がった工事、選ばれた色、いただいたご質問などです。リンクや割引を入れると広告に見えるので、別の機会に回します。

こちらの番号を登録していないお客様もいるので、最後に必ず名前か社名を書きます。

例文の{last_name}と{company}は差し込み項目です。手で書き換えるか、アプリにお客様ごとに入れてもらいます。

ご購入、ご来店のお礼メッセージ 例文

初めてのお客様には、ご購入の当日にお礼を送ります。記憶が新しいうちに届くからです。購入や予約の内容に触れ、困ったときの連絡方法を添えましょう。一度きりのお客様に番号を覚えてもらえるのは、このメッセージです。

  1. {last_name}様、本日は{company}にお越しいただきありがとうございました。不具合などあれば、このメッセージにご返信ください。[名前]
  2. {last_name}様、初めてのご注文ありがとうございます。小さな店にとって大変励みになります。{company}
  3. {last_name}様、本日はお会いできてうれしかったです。ご信頼に感謝いたします。ご質問はいつでもどうぞ。[名前]
  4. {last_name}様、ご購入ありがとうございました。気に入っていただけますように。使い心地もぜひお聞かせください。[名前]

納品、作業完了後のお礼メッセージ 例文

納品や作業の完了後は、2日以内にお礼を送り、うまくいった点を一つ書きます。請求書より先に届くほうが印象に残ります。お客様は最後に受け取ったメッセージを覚えているので、ここではお金や次の話はしません。

  1. {last_name}様、作業がすべて完了しました。お任せいただきありがとうございました。[名前]
  2. {last_name}様、今回はすぐにご返答いただきありがとうございました。おかげでよい仕上がりになりました。[名前]
  3. {last_name}様、ありがとうございました。ご一緒できて楽しく、仕上がりにも満足しています。[名前]
  4. {last_name}様、今回は{company}にご依頼いただきありがとうございました。何かあればいつでもご連絡ください。

長いお付き合いのお客様へのお礼メッセージ 例文

長いお付き合いのお客様は、新しいお客様より連絡を受ける機会が少ないものです。だからこそ短いお礼が届きます。特別な理由がなくてもかまいませんし、初回ご注文の記念日でも結構です。割引は付けないでください。お礼が営業に見えてしまいます。

  1. {last_name}様、初めてのご来店から3年が経ちました。いつもありがとうございます。[名前]
  2. {last_name}様、特に用件はありませんが、{company}をご利用いただいているお礼をお伝えしたくご連絡しました。
  3. {last_name}様、いつも応援いただきありがとうございます。この仕事を続けられるのは皆様のおかげです。[名前]
  4. {last_name}様、最初からお付き合いいただいたこと、忘れておりません。ありがとうございます。[名前]

ご紹介、口コミへのお礼メッセージ 例文

ご紹介や口コミへのお礼は1日以内に送り、紹介された方や書かれた内容に触れます。紹介してくださる方は、ご自身の信用を預けてくださっています。早く具体的に返すことがそのお礼になります。同じメッセージで別のお願いはしません。

  1. {last_name}様、[紹介された方]様をご紹介いただきありがとうございました。ご信頼に感謝いたします。[名前]
  2. {last_name}様、口コミを拝見しました。ありがとうございます。小さな店にとって大きな力になります。[名前]
  3. {last_name}様、{company}をご紹介いただきありがとうございます。新しいお客様の多くは、皆様のご紹介でいらっしゃいます。
  4. {last_name}様、[紹介された方]様からご紹介のことを伺いました。本当にありがとうございます。[名前]

年末のお礼メッセージ 例文

年末のお礼は一年を振り返るメッセージで、季節の挨拶がなくても送れます。12月15日から30日の間に送り、今年一緒にしたことを一つ書きましょう。しばらく連絡のなかったお客様に声をかけるよい機会にもなります。

  1. {last_name}様、本年もお世話になりありがとうございました。来年もよい一年になりますように。[名前]
  2. {last_name}様、年内にお礼をお伝えしたくご連絡しました。{company}にとって大きな支えでした。
  3. {last_name}様、今年を振り返ると、ご一緒したお仕事が一番の思い出です。ありがとうございました。[名前]
  4. {last_name}様、2026年もご信頼いただきありがとうございました。{company}一同、感謝申し上げます。

グループを作らず全員にお礼を送る方法

お客様には一人ずつ別のメッセージを送ります。グループにすると、お互いの番号や返信がすべて見えてしまい、お礼の気持ちも薄れます。人数が少なければ、トークごとに文面を貼り付けて名前を変えます。人数が多ければ、一斉送信アプリがその作業を代わりに行います。

iPhoneでは、Sendrがメッセージアプリを通じて、あなたの番号から一人ずつ別のメッセージを送ります。{last_name}を入れて文面を1回書き、連絡先か保存したグループを選び、確認して送信の画面で1通ずつ確認します。どのメッセージにも個別に一言足せます。1件ずつ送信は無料で、Sendrがお客様ごとにメッセージを開き、送信はあなたがタップします。Proの自動で送信は、ショートカットを1回設定すれば、iPhoneのロックが解除されている間リストを順に処理します。終わるとレポートで、送れた相手と送れなかった相手がわかります。iMessageとSMSには写真や動画を3つまで付けられます。SendrはiPhone専用です。

SMSで届く可能性がある文面は、全角70字を目安にしましょう。超えると分割され、料金が変わる場合があります。

SMSの文字数は2026年11月に確認しました。

よくある質問

お取引のお礼はメッセージでどう書けばよいですか?

シンプルで十分です。「{last_name}様、いつもお取引いただきありがとうございます。」と書き、購入内容や一緒に進めた仕事を一言添えると、定型文に見えません。

お客様からお礼を言われたら何と返しますか?

お役に立てた喜びを伝え、次の連絡につなげます。「{last_name}様、こちらこそありがとうございました。またいつでもご連絡ください。」一行で足ります。

メッセージと手書きのお礼状はどちらがよいですか?

手書きは手間がかかる分、大切なお客様の心に残ります。ご購入の当日など早さが大事なときや、普段からメッセージでやり取りしているお客様にはメッセージが向いています。

お礼メッセージに割引を入れてもよいですか?

別で送るほうがよいでしょう。クーポンが付くと広告に見えますし、広告目的のメッセージには事前の同意が必要になる場合があります。適用されるルールを確認してください。
